# cursor-shared-tasks

Общий репозиторий для задач с двух ноутбуков (ORION + VAJRAPANI) через **Cursor Cloud Agents**.

## Как работать

1. На любом ноутбуке откройте этот репозиторий в Cursor.
2. Agents Window → окружение **Cloud**.
3. Опишите задачу в Cloud Agent.
4. На втором ноутбуке откройте тот же агент: <https://cursor.com/agents>
5. Код подтягивайте через `git pull` / ветку агента.

Подробнее: `D:\Yandex.Disk\AI-Cursor\Cursor-Sync\CLOUD-TASKS.md` (на ORION путь может быть `C:\YandexDisk\AI\Cursor-Sync`).

## Структура

- `tasks/` — краткие заметки по задачам (опционально)
- `AGENTS.md` — постоянный контекст для агента
